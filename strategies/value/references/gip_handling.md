# 增长投资期（GIP）处理

> 当一家公司处于增长投资期（Growth Investment Phase, GIP），它的财务报表看起来"很糟糕"——利润被研发投入压低、FCF 被资本开支吞噬、资产负债表杠杆偏高——但这些信号反映的是"把当期利润再投资为未来产能"，而不是"经营恶化"。
>
> 如果不做 GIP 区分，框架会对一家正在建设全球产能的龙头公司给出和一家衰亡中重资产公司相同的保守估值。这是格雷厄姆式的误判。

---

## 触发条件

`value_computed.md` 中"跨周期归一化判断"表格的"是否处于增长投资期（GIP）"为"是"。

---

## GIP 五条处理规则

### 1. 重新审视估值锚

- 不要把"8 年归一化 Owner Earnings"当作唯一锚值——8 年前的公司是另一家公司
- 考虑使用**最近 3 年归一化**或**当前利润 × 合理的维持性 Capex 调整**作为替代锚
- 维持性 Capex 系数可以从 Python 默认的 1.20x 降低到 **1.00x**（即维持性 Capex ≈ D&A，超出部分视为增长性投资）
- 明确写出理由：这个调整是因为公司的 Capex/D&A>1.3x 中有大量属于建设未来产能的增长性投资

### 2. 重新审视增长假设

- Python 默认增长可能因周期判断被压在 5% 以下，对于 GIP 公司这严重低估了实际增长能力
- 应结合公司历史增速、行业渗透率空间、海外扩张节奏，给出**更符合商业现实的增长假设**
- 允许使用两阶段模型：第 1-5 年使用接近当前趋势的增速（如 10-15%），第 6-10 年向终值增长率衰减

### 3. 重新审视要求回报率

- Python 默认要求回报率因高杠杆和防守层 Adequate 而被推高，对于 GIP 公司这种推高是被动且可能过度的
- 如果公司杠杆的用途是建设未来盈利资产（而非维持亏损运营），要求的风险补偿应当更低
- 允许在 Python 默认基础上**下调 1-2 个百分点**，但必须写清原因

### 4. 不要误用毛毛估参考价

- 毛毛估参考价（owner-yield 资本化）对 GIP 公司几乎毫无意义——它假设零增长且所有 Capex 都是浪费
- GIP 公司的主要价值来自**未来投资完成后的盈利释放**，而非当前的 owner-yield
- 报告中必须明确说明"毛毛估价格不适用于处于增长投资期的公司"

### 5. 区分"现在赚不到钱"和"永远赚不到钱"

- GIP 公司的 FCF 为负是因为它在建工厂、搞研发、铺渠道——这些投资的目的恰恰是未来赚更多钱
- 如果定性分析确认公司确实在建设有长期价值的资产（而非无效扩张），负 FCF 不是否决理由
- 报告应同时给出"当前投资期的盈利"和"投资完成后的稳定期盈利"两套视角

---

## 重要约束

GIP 不是"可以无限制上调估值"的通行证。如果定性分析发现：

- 投资回报率持续下降（新增 Capex 对应的增量 ROE 越来越低）
- 行业产能严重过剩，新增产能可能无法充分利用
- 管理层有"为扩张而扩张"的历史

→ 则应限制 GIP 优惠力度，甚至回到保守模式。

GIP 调整必须在报告中**显式记录**：写清 Python 默认 vs 调整后、调整依据、以及"如果我判断错了会怎样"的反方论证。
