# 风险画像矩阵 — Risk Profile Matrix (v2.0)

> 定义用户风险画像的分级标准、推导规则，以及每个风险等级对应的资产配置约束。
>
> **v2.0 变更**：另类资产全部条件化，数字资产上限大幅下调，现金下限大幅上调。R5 回撤容忍度扩展至 -50%（v2.0 哲学：年轻人核心资产回撤不是灾难而是机会）。

---

## 1. 风险承受等级定义

| 等级 | 标签 | 最大可接受回撤 | 波动容忍 | 典型人群 |
|------|------|-------------|---------|---------|
| R5 | 激进型 | -50% (v2.0放宽) | 高波动无感 | 20-28岁、资产<100万、稳定收入 |
| R4 | 积极型 | -25% | 阶段性关注但不恐慌 | 28-35岁、资产100-300万 |
| R3 | 平衡型 | -15% | 波动引发焦虑但不行动 | 35-45岁、资产300万+、有家庭负担 |
| R2 | 稳健型 | -10% | 不想看到两位数回撤 | 45-55岁、临近退休/大额支出 |
| R1 | 保守型 | -5% | 保本优先 | 55岁+、退休后、本金不可损失 |

## 2. 风险等级自动推导规则

### 2.1 主推导：年龄 → 风险等级

| 年龄 | 默认等级 | 置信度 | 说明 |
|------|---------|--------|------|
| 18-22 | R5 | 高 | 大学生/初入职场、人力资本极高 |
| 22-25 | R5 | 高 | 职业生涯起步、试错成本低 |
| 25-28 | R4-R5 | 中高 | 开始有积蓄，但时间窗口仍长 |
| 28-32 | R4 | 中 | 职业稳定期、可能开始考虑购房 |
| 32-35 | R3-R4 | 中 | 家庭形成期、财务责任增加 |
| 35-40 | R3 | 中 | 子女教育/房贷/中年压力 |
| 40-45 | R2-R3 | 中 | 退休准备期启动 |
| 45+ | R2 | 中高 | 保本需求上升 |

### 2.2 修正因子

| 因子 | R5→R4 | R4→R3 | R3→R2 | R2→R1 |
|------|--------|--------|--------|--------|
| 有房贷 (>年收入3倍) | 是 | 是 | 否 | 否 |
| 有子女 (< 18岁) | 否 | 是 | 是 | 否 |
| 单收入家庭 | 是 | 是 | 是 | 否 |
| 资产>年收入10倍 | 否 | 否 | 否 | 是 |
| 未来2年有大额支出 | 是 | 是 | 是 | 是 |
| 职业不稳定 (自由职业/创业) | 是 | 是 | 否 | 否 |
| 有稳定被动收入 (>支出50%) | +1 | +1 | +1 | 0 |
| 投资经验 > 5年 | +1 | +1 | 0 | 0 |

> "+1" = 可以上调一级风险；"是" = 下调一级风险；"否" = 不影响

### 2.3 用户手动指定优先

如果用户明确声明风险承受等级，以用户声明为准。自动推导仅用于用户未指定的情况。

**但必须提示**：如果用户声明的风险等级与自动推导偏差 ≥ 2级（如40岁声明R5），给出风险提示，但尊重用户选择。

## 3. 各等级资产配置约束

### 3.1 大类资产上下限（v2.0）

| 约束 | R5 激进 | R4 积极 | R3 平衡 | R2 稳健 | R1 保守 |
|------|---------|---------|---------|---------|---------|
| 权益上限 | 75% | 65% | 55% | 45% | 30% |
| 权益下限 | 40% | 30% | 25% | 15% | 10% |
| 固收下限 | 5% | 10% | 15% | 25% | 45% |
| 条件类上限 | 6% | 5% | 3% | 0% | 0% |
| 现金下限 | 15% | 15% | 15% | 20% | 25% |
| 数字资产上限(条件) | 3% | 0% | 0% | 0% | 0% |

> **v2.0 核心变化**：另类资产全部条件化（不进入默认基准）。"另类上限"改为"条件类上限"（黄金+数字+REITs 合计）。现金下限从 3% 提升至 15%。数字资产仅 R5 且条件满足时可配 3%。

### 3.2 单票/单市场集中度（按总资产百分比）

| 约束 | R5 | R4 | R3 | R2 | R1 |
|------|-----|-----|-----|-----|-----|
| 单票上限 | 15% | 12% | 10% | 8% | 5% |
| 单行业上限 | 35% | 30% | 25% | 20% | 15% |
| 单市场上限 | 55% | 50% | 45% | 40% | 35% |
| 低流动性上限 | 25% | 20% | 15% | 10% | 5% |

### 3.3 目标波动率

| 等级 | 目标年化波动率 | 目标最大回撤 |
|------|-------------|------------|
| R5 | 15-20% | -35% |
| R4 | 12-16% | -25% |
| R3 | 8-12% | -15% |
| R2 | 5-8% | -10% |
| R1 | 2-5% | -5% |

## 4. 资产分层（桶策略）参数化

### 4.1 三桶配比（按风险等级，v2.0）

| 桶 | R5 | R4 | R3 | R2 | R1 |
|----|-----|-----|-----|-----|-----|
| **安全桶** (流动资金) | 5% | 10% | 15% | 20% | 30% |
| **成长桶** (长期增值) | 75% | 70% | 60% | 50% | 35% |
| **现金弹药桶** (机会储备) | 20% | 20% | 25% | 30% | 35% |

> **v2.0 变更**：将 v1.0 的"机会桶"（另类/加密）改为"现金弹药桶"。20 岁时最好的机会是熊市买入优质公司。另类资产是条件性配置，不占固定桶位。

### 4.2 安全桶覆盖规则

安全桶金额 = max(6个月生活费, 未来2年内确定性大额支出)

如果用户流动资产不足安全桶目标：
- 优先用增量资金填充安全桶
- 安全桶未填满前，不得向机会桶追加

## 6. 动态风险调整触发条件

组合运行中，若发生以下事件，触发风险等级重新评估：

| 事件 | 动作 |
|------|------|
| 用户年龄跨越阈值（25/30/35/40/50） | 自动下调风险等级，给出新配置建议 |
| 资产规模翻倍 | 审查风险等级是否仍合适 |
| 用户结婚/生子/购房 | AskUserQuestion 重新采集画像 |
| 组合回撤超过可接受上限 | 审查是否风险等级设定错误 |
| 用户主动要求调整 | 重新运行完整画像评估 |
