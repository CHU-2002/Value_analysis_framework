# 各类资产操作手册 — Asset Class Playbook (v2.0)

> 定义每一类可投资资产的特性和操作指南，包括：核心逻辑、估值警示、可用分析工具、推荐工具、风险注意事项。
>
> **v2.0 核心变革**：删除"行业ETF层"、"其他市场权益"、"大宗商品"等章节。ETF 降级为过渡工具，另类资产降级为条件性配置。每个资产类别都引入"什么时候不买"的估值警示。

## 1. 中国 A 股精选

### 1.1 核心逻辑
A股是 20 岁中国投资者的天然主场。优势在于：
- 无汇率风险
- 个人投资者信息优势（理解本土消费者/品牌）
- 龟龟策略框架已深度覆盖 A 股

劣势：
- 政策风险高（监管突然转向）
- 散户主导、波动大
- 长期指数回报（沪深300年化8-10%）不如美股但含股息后体面

### 1.2 估值警示（v2.0 新增）

> **什么时候不应该买 A 股？**
> - 沪深 300 PE(TTM) > 16（历史 70 分位以上）
> - 创业板 PE(TTM) > 50（历史 80 分位以上）
> - 市场情绪极度亢奋（新基金日光盘、散户排队开户）

当前估值状态应在每次 `macro_assessment.md` 中明确标注。如果处于高位，A股权益部分应降低至少 -10%，提高现金。

### 1.3 配置策略（v2.0 集中版）

| 层级 | 占比(A股内部) | 工具 | 备注 |
|------|-------------|------|------|
| **龟龟精选（核心）** | 70-100% | 3-5 支高分个股 | 等权重，单票 ≤ 总组合 15% |
| 指数占位（过渡） | 0-30% | 沪深300ETF(510300) | **仅在研究未完成时使用** |

> **v2.0 删除的层级**：中证500ETF、创业板ETF、消费ETF、医药ETF、科技ETF。理由：如果你不了解创业板里的公司，就不要投创业板。行业 ETF 无法替代对具体公司的理解，它只会给你一种"我已经分散了"的虚假安全感。

### 1.4 选股流程 (龟龟路径)

```
1. screener_core.py → 筛选池 (Tier 2 得分 ≥ 70 + 无硬否决)
2. 取 Top 15-20，但不要按行业分散 —— 聚焦你理解的方向
3. 对候选标的逐次 /business-analysis → /turtle-analysis
4. 选 Buy 评级且 moat_rating ≥ "中" 的 3-5 支
5. 等权重配置，单票 ≤ 总资产 15%
6. 季度检查（重要季报/年报后复查 moat_rating）
```

### 1.5 风险注意事项
- 不要高估自己对"本土品牌"的判断力；护城河判断需要数据支撑
- 小市值股票流动性风险：龟龟策略池中市值下限建议 > 100亿
- 警惕"本地偏见"：不要因为熟悉就超配中国消费股
- 精选 3-5 支不等于押注一个行业。如果 5 支全是白酒，你没有分散

## 2. 香港股票精选

### 2.1 核心逻辑
港股是中国投资者可触及的最方便的境外权益市场。核心价值在于：
- 腾讯/阿里/美团等中国互联网巨头（A股无法直接买到）
- 国际化公司（友邦、汇丰等）
- 部分标的因流动性折价而估值低于 A 股

### 2.2 估值警示（v2.0 新增）

> **什么时候不应该买港股？**
> - 恒指 PE(TTM) > 15（历史 80 分位以上）
> - 恒生科技 PE > 30 且无盈利改善预期
> - 港股通资金持续大幅流出

### 2.3 配置策略（v2.0 集中版）

| 层级 | 占比(港股内部) | 工具 | 备注 |
|------|-------------|------|------|
| **价值精选（核心）** | 70-100% | 1-2 支深度分析过的优质港股 | 单票 ≤ 总组合 10% |
| 指数占位（过渡） | 0-30% | 恒生科技ETF(03033) | **仅在研究未完成时使用** |

> **v2.0 删除的层级**：盈富基金、恒生高股息ETF。如果你真的看好高股息，直接买那家公司的股票。

### 2.4 选股流程 (价值路径)

```
1. 基于 screener 或手动筛选香港蓝筹
2. /business-analysis → /value-analysis
3. 重点考察: ROE稳定性、分红记录、管理层诚信
4. 港股精选不超总权益仓位的 30%
5. 精选 1-2 支即可，不追求"覆盖"
```

### 2.5 港股特有风险
- **股息税**：港股通 20%（红筹可能 28%），直接持有 H 股 10%
- **流动性**：中小市值港股流动性极差，价差可能超过 2%
- **停牌风险**：港股长期停牌不罕见，且复牌无时间表
- **做空风险**：港股做空机制成熟，单票容易遭遇空头狙击
- **老千股**：合股、供股等手段，必须严格筛选

## 3. 美国股票精选

### 3.1 核心逻辑
美股是全球最大的资本市场。对 20 岁中国投资者的核心价值在于：
- 全球最优秀的公司（通过 BRK.B 一次购买就完成分散）
- 制度成熟、信息透明

劣势：
- 中国投资者面临外汇管制
- 时差和语言障碍
- 对中国投资者税收不利（股息预扣税 10-30%，遗产税风险）

### 3.2 估值警示（v2.0 新增）

> **什么时候不应该买美股？**
> - S&P 500 CAPE(Shiller PE) > 32（历史 85 分位以上，如当前）
> - Nasdaq PE(TTM) > 35 且无盈利增速支撑
> - 散户保证金债务/市值创新高（市场亢奋信号）
> - 巴菲特指标（总市值/GDP）> 150%

如果当前 CAPE > 30，美股配置应至少降低至基准下限，且只通过 BRK.B 持有。不追逐高估值科技股。

### 3.3 配置策略（v2.0 集中版）

| 层级 | 占比(美股内部) | 工具 | 备注 |
|------|-------------|------|------|
| **伯克希尔B（核心）** | 50-70% | BRK.B | 巴菲特自己的组合，天然分散，费率 0% |
| 科技巨头精选 | 0-30% | 0-2 支你真正理解的公司 | 如 MSFT/GOOGL/AAPL/AMZN |
| 指数占位（过渡） | 0-20% | SPY / QDII:513500 | 仅在无法买到 BRK.B 时替代 |

> **v2.0 核心逻辑**：BRK.B 本身就是一个分散化的美股组合（持有苹果、可口可乐、美国运通、西方石油等 + 2800亿美元现金 + 全资子公司）。买 BRK.B 就是在买巴菲特的资产配置能力，费率为 0。除非你确信自己能跑赢巴菲特，否则 BRK.B 应该是你美股仓位的核心。

> **v2.0 删除的层级**：标普500 ETF、纳斯达克100 ETF、行业ETF（XLK/SOXX/XLV）。BRK.B 可以替代所有这些东西。

### 3.4 操作指南
- BRK.B 是你的"一键美股"工具。先买它，再考虑是否需要其他。
- 如要对美股跑 /turtle-analysis，使用 yfinance fallback（`--code AAPL.US`），但精度有限。
- 注意中美双重征税问题

### 3.5 工具获取途径
- **QDII基金**：人民币直接购买，如纳指ETF(513100)、标普ETF(513500)
- **境外券商**：盈透证券(IBKR)、嘉信理财等（可买 BRK.B）
- **香港券商**：富途、老虎等

## 4. 固定收益（极度精简）

### 4.1 核心逻辑

对 20 岁高风险投资者，债券的唯一作用：
- **提供流动性和危机缓冲**
- **在股市大跌时有弹药加仓**
- 不是用来追求收益的

### 4.2 配置策略（v2.0 简化版）

| 子类 | 工具 | 代码 | 使用条件 |
|------|------|------|---------|
| 货币基金（安全桶） | 余额宝/零钱通 | - | 永久保留，至少覆盖 6 个月生活费 |
| 中国短债 | 短债基金 | 007019 | 安全桶之上需要固收时 |
| **美国短债** | **SHV (1-3年)** | **SHV** | **仅在美债收益率 > 4% 时** |

> **v2.0 删除的固收工具**：中国国债ETF(511010) — 不要在 2.5% 的收益率上赌利率下行。美国中债(IEF) — 不需要。美国长债(TLT) — 你不是债券交易员。信用债基金 — 信用研究成本高，收益补偿不足。

### 4.3 什么时候配更多固收？
- 当多市场同时处于历史估值高位 → 大幅提高现金（本身就是固收）
- 当美债收益率 > 5% → 这是十年一遇的机会，可超配

### 4.4 不推荐
- 不推荐单一信用债（信用风险研究成本高、收益补偿不足）
- 不推荐理财/信托产品（刚兑已破，底层不透明）
- 不推荐 P2P/民间借贷

## 5. 另类资产（v2.0 — 全部条件化）

v2.0 中，所有另类资产都是条件性配置，不在默认组合中。

### 5.1 黄金（条件性）

| 属性 | 说明 |
|------|------|
| 角色 | 组合保险（对冲通胀、地缘风险、系统性危机） |
| 纳入条件 | ① 地缘风险显著 ② 金价不在历史新高 |
| 配置上限 | 0-5%（高风险年轻人） |
| 工具 | 黄金ETF(518880) |
| 不纳入时 | 资金还给现金或权益 |
| 收益特征 | 不生息、不含现金流，长期实际收益 ≈ 0-1% |

> **估值警示**：如果金价处于历史新高（如当前 $4,500+），即使有地缘风险，也不应大举配置。历史上金价在创新高后的 3 年回报通常为负。

### 5.2 REITs（条件性 — 仅现金流需求）

| 属性 | 说明 |
|------|------|
| 角色 | 提供定期现金流（租金分红） |
| 纳入条件 | ① 用户明确要求 ② 现金流是明确目标（如退休/半退休） |
| 配置上限 | 0-3% |
| 注意事项 | 中国REITs起步阶段、底层资产差异大 |
| 不纳入时 | 不做配置，20 岁不需要追求分红 |

### 5.3 数字资产（条件性 — 仅合规 + 用户要求）

| 属性 | 说明 |
|------|------|
| 角色 | 高风险非对称机会（损失有限、上行空间大） |
| 纳入条件 | ① 用户明确要求 ② 有合规渠道（香港） ③ 非狂热期 |
| 配置上限 | 3%（R5）/ 0%（R4 及以下） |
| 禁令 | 不碰山寨币、不碰合约杠杆、不碰 DeFi 挖矿 |
| 不纳入时 | 资金还给现金或权益 |

> 中国大陆禁止加密货币交易。此项仅适用于有香港合规账户且用户明确要求的场景。**v2.0 默认不推荐数字资产。**

### 5.4 已删除的资产类别

| 被删除资产 | 原因 |
|-----------|------|
| 日本/欧洲/新兴市场 ETF | 不了解就不投。分散化不是目的，理解才是 |
| 大宗商品 | 需期货账户，研究成本高，20 岁没必要 |
| 行业 ETF（消费/科技/医药 ETF） | 给你的虚假分散感，代替不了对公司本身的理解 |
| 中国长债 ETF | 在 2.5% 收益率赌利率下行，性价比极低 |
| 美国中长债 ETF | 你不是债券交易员 |
| 恒生高股息 ETF | 真要高股息直接买那家公司 |

## 6. 跨资产操作原则

### 6.1 买入原则（v2.0 估值优先）

1. **不要在历史新高 ALL IN**：任何资产处于历史估值 80 分位以上时，最多建仓 30%，其余现金等待
2. **下跌时按计划加仓**：优质标的下跌 30%（基本面未变）→ 加仓。不是恐慌清仓。
3. **不追热点**：媒体热炒的行业/主题往往是高点。AI 狂热时追 NVDA 往往是买在顶部。
4. **先研究后买入**：不因为"ETF 占位"而跳过研究。ETF 是过渡，不是借口。
5. **不知道买什么时 → 现金**：现金永远是一个合法选择。比买错东西好一万倍。

### 6.2 卖出原则

1. **逻辑破坏必须卖**：公司护城河消失、管理层造假、行业颠覆，不论盈亏
2. **估值过高减仓**：超过内在价值 +30%，减仓但不一定清仓
3. **不要因为"涨太多了"就卖**：好公司可以涨 10 年。巴菲特持有可口可乐 30+ 年。
4. **不要因为"跌太多了"就卖**：除非逻辑破坏。下跌时检查基本面，而不是看股价。

### 6.3 税收优化 (中国投资者)

| 资产 | 税收要点 |
|------|---------|
| A股 | 持股 > 1年免股息税；资本利得暂免 |
| 港股(港股通) | 股息税 20%；资本利得暂免 |
| 港股(直接) | H股股息税 10%；红筹 20% |
| 美股 | 股息预扣税 10%(有W-8BEN) / 30%(无协议)；资本利得暂免 |
| 境内基金 | 基金分红暂免个人所得税 |
| QDII基金 | 底层境外资产可能被双重征税 |

## 7. 不推荐资产（v2.0 扩展）

| 资产 | 原因 |
|------|------|
| 行业 ETF | 代替不了对公司本身的理解，只是给你虚假的安全感 |
| 其他市场 ETF（日/欧/新兴） | 不了解就不买 |
| 大宗商品 | 需期货账户，研究成本高 |
| 中国长债 ETF | 2.5% 收益不值得冒利率风险 |
| 美国中长债 ETF | 你不是债券交易员 |
| 私募股权/VC | 锁定期长、信息不透明、不适合 50 万级别 |
| 结构化产品/雪球 | 条款复杂、尾部风险大 |
| 外汇保证金/CFD | 不是投资而是赌博 |
| 艺术品/收藏品 | 流动性极差 |
| 山寨币/Meme币 | 99% 归零 |
| 期权/Warrant (非对冲用途) | 时间衰减陷阱 |
