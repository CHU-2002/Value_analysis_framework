# 再平衡规则详解 — Rebalancing Rules (v2.0)

> 定义组合再平衡的触发条件、执行方法和税收考虑。

---

## 1. 再平衡的核心逻辑

再平衡的作用：
- **控制风险**：防止某类资产暴涨后权重失控
- **被动低买高卖**：卖出超涨的、买入超跌的
- **纪律约束**：减少情绪驱动的交易

再平衡不是择时——它是一种**风险控制机制**。

---

## 2. 触发规则（三条独立规则，满足任一即触发）

### 规则 1：定期再平衡（日历触发）

| 项 | 设定 |
|----|------|
| 频率 | 每年 1 次 |
| 建议时间 | 每年 3 月（年报季结束后，信息最充分） |
| 执行范围 | 全组合检查 |
| 额外条件 | 无 |

**流程**：
```
每年 3 月：
1. 运行 Step 1 宏观评估（更新宏观情景）
2. 检查所有持仓是否仍满足原投资逻辑
3. 计算各类资产偏离度
4. 执行再平衡交易
5. 更新再平衡记录
```

### 规则 2：阈值再平衡（偏离触发）

| 项 | 设定 |
|----|------|
| 触发条件 | 任一大类资产偏离目标权重 ≥ 绝对 10% |
| 示例 | 权益目标 70%，实际达到 82% → 触发 |
| 执行范围 | 仅调整偏离的资产类别 |
| 额外条件 | 偏离持续 ≥ 5 个交易日（避免盘中毛刺触发） |

**偏离度计算**：

```
偏离度 = 实际权重 - 目标权重

权益偏离 = 82% - 70% = +12% → 触发
固收偏离 = 8% - 10% = -2% → 不触发
黄金偏离 = 8% - 5% = +3% → 不触发
```

### 规则 3：危机再平衡（大跌触发）

| 项 | 设定 |
|----|------|
| 触发条件 | 组合整体从高点回撤 ≥ 20% |
| 动作 | 安全桶资金逐步转权益（每次安全桶的 20%，每月一次） |
| 限制 | 安全桶余额不得低于 3 个月生活费 |
| 停止条件 | 权益占比回到目标权重上限，或回撤修复 |

## 3. 再平衡执行方法

### 3.1 资金流向优先

再平衡时优先使用**增量资金**（新存入的资金），避免产生交易成本和税收。

```
优先级：
1. 增量资金注入 → 买入低配资产
2. 分红/利息收入 → 再投资到低配资产
3. 卖出超配资产 → 买入低配资产（最后手段）
```

### 3.2 税收损失收割 (Tax-Loss Harvesting)

对于有资本利得税的市场（如境外券商账户的美股），再平衡时可以：
- 卖出亏损的持仓，实现亏损 → 抵减资本利得税
- 同时买入高度相关但不完全相同的替代资产（避免 wash sale 规则）

> 中国大陆目前暂免股票资本利得税，TLH 主要对境外账户有用。

### 3.3 带宽度带

为避免频繁小额交易，设立"容忍带"：

| 资产权重 | 容忍带 | 超过此带才交易 |
|---------|--------|--------------|
| > 20% | ±5% | 偏离超过目标 ±5% |
| 10-20% | ±3% | 偏离超过目标 ±3% |
| 5-10% | ±2% | 偏离超过目标 ±2% |
| < 5% | ±1% | 偏离超过目标 ±1% |

## 4. 各类资产的再平衡细则

### 4.1 权益内部再平衡

| 情景 | 操作 |
|------|------|
| A股跑赢美股 > 15% | 减仓A股ETF → 加仓美股ETF |
| 美股跑赢A股 > 15% | 减仓美股ETF → 加仓A股ETF |
| 龟龟精选单票盈利 > 50% | 审查估值是否超过内在价值+20%，超标则减半仓 |
| 龟龟精选单票亏损 > 30% | 审查投资逻辑是否破坏 → 是则清仓，否则持有/加仓 |

### 4.2 固收再平衡

固收再平衡优先使用**到期资金**和**利息收入**，较少主动交易：
- 债券 ETF 可直接交易
- 持有至到期的个债等待到期后重新分配

### 4.3 另类资产再平衡

| 资产 | 特殊性 |
|------|--------|
| 黄金 | 不产生现金流，再平衡时直接买卖 ETF |
| REITs | 分红再投资到低配资产 |
| 数字资产 | 高波动，容忍带放宽到 ±5%；不因暴涨追涨 |

## 6. 不执行再平衡的情况

| 情况 | 原因 |
|------|------|
| 偏离在容忍带内 | 成本大于收益 |
| 触发时间距上次再平衡 < 30 天 | 避免过度交易 |
| 交易成本 > 预期再平衡收益 | 计算阈值：若交易费+税 > 再平衡金额的 0.5%，放弃 |
| 某类资产逻辑已破坏 | 不是再平衡，而是清仓 |
| 安全桶余额不足 | 不执行"动用安全桶"类的再平衡 |
