# 经营变化报告 — 五粮液 · 2026H1

## 经营与利润发生了什么变化

比较期间：2026H1与2025H1。下列同比按累计口径比较；不将累计数当作单季数。

- 营业收入同比变化尚未核实，不能判断幅度。
- 归母净利润同比变化尚未核实，不能判断幅度。

## 重要事项与主要解释

### 2026年更正2025年前三季度部分报表项目

披露日期：2026-04-30；涉及期间：2025年一季度、半年度、三季度。

**事项说明（公司解释）**：公司根据业务模式梳理，调整2025年部分业务收入确认核算。

**术语解释（分析推断）**：会计差错更正是把以前报出的数字按调整后口径重新列报，不能单凭更正定性为财务造假。

**为什么重要（分析推断）**：比较2025年和其他期间时应使用重述口径，不能混用旧数。

**报表金额与口径（已披露事实）**：2025H1营业收入由52,770,984,383.52元调整为23,509,972,048.65元；归母净利润由19,491,942,398.53元调整为4,623,850,715.13元。

**影响（已披露事实）**：涉及合并资产负债表、合并利润表部分项目；公司披露现金流量表列示不受影响。

**尚不能确定（未核实事项）**：本公告未对2025年更正事项作出监管造假认定；不能将历史处罚挪用到这个期间。

来源：[五粮液关于前期会计差错更正的公告（2026/第011号）](https://static.cninfo.com.cn/finalpage/2026-04-30/1225273122.PDF)，2026-04-30，第1页原因与影响；第3—4页2025半年度更正表。

### 2011年历史信息披露违法处罚与本次更正分开理解

披露日期：2011-04-29；涉及期间：2001—2009年证券投资及2007年年报、董事事项。

**事项说明（监管确认事实）**：证监会认定历史信息披露违法，包括澄清公告重大遗漏、证券投资披露不及时不完整、2007年年报录入差错未及时更正和董事受司法羁押未及时公告。

**为什么重要（分析推断）**：这些认定涉及历史信息披露可信度；不能拿来替代2025年更正事项的监管判断。

**报表金额与口径（监管确认事实）**：对五粮液给予警告并处罚款60万元；该罚款属于2011年决定，不是2026年财务影响。

**影响（监管确认事实）**：行政处罚决定已作出；涉及的主体与行为范围以决定原文为准。

**尚不能确定（未核实事项）**：后续复议、诉讼或执行状态未核实；没有依据认定2025年更正事件为财务造假。

来源：[证监会行政处罚决定书（五粮液、唐桥等8名责任人员）〔2011〕17号](https://www.csrc.gov.cn/csrc/c101928/c1043253/content.shtml)，2011-04-29，违法事实一至四、处罚决定第一项及文末落款。
