## 重要事项与主要解释

### 澳优商誉及存货减值增加，本期利润受到影响

披露日期：2026-08-27；涉及期间：2026年1—6月。

**事项说明（公司解释）**：公司说明资产减值增加主要来自澳优商誉及存货减值增加。

**术语解释（分析推断）**：商誉减值是收购形成的预期价值被判断部分无法收回后确认的费用。存货减值是库存商品等预计卖不回原成本的部分确认损失。

**为什么重要（分析推断）**：减值降低本期利润及相关资产账面价值，需要与持续经营表现分开理解。

**报表金额与口径（已披露事实）**：合并口径、人民币元：资产减值损失2,455,875,173.02；其中商誉减值1,546,544,866.49，存货跌价损失及合同履约成本减值损失本期907,520,836.34，上期315,591,928.82。利润表以负数列示损失。存货行合并含合同履约成本，不擅自拆分。

**影响（分析推断）**：这是税前费用；确认减值不等于当期支付同额现金。

**尚不能确定（未核实事项）**：税费、少数股东影响及各因素对归母利润下降的贡献未逐项核实，不能把税前减值等同于归母净利润下降额，也不能说它单独解释全部下降。

来源：[伊利2026年半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-27/1225511409.PDF)，2026-08-27，印刷第164页（PDF第167页），附注七（73）资产减值损失；第140页商誉减值准备；第49页合并利润表。
