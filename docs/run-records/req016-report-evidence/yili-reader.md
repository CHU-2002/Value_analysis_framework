# 经营变化报告 — 伊利股份 · 2026H1

## 经营与利润发生了什么变化

比较期间：2026H1与2025H1。下列同比按累计口径比较；不将累计数当作单季数。

- 营业收入同比增长4.13%。
- 归母净利润同比下降20.02%。

## 重要事项与主要解释

### 澳优商誉及存货减值增加，本期利润受到影响

**公司解释**；披露日期：2026-08-27；涉及期间：2026年1—6月。

公司说明资产减值增加主要来自澳优商誉及存货减值增加。商誉减值是收购形成的预期价值被判断部分无法收回后确认的费用。

为什么重要：减值降低本期利润及相关资产账面价值，需要与持续经营表现分开理解。

报表金额与口径：合并口径、人民币元：资产减值损失2,455,875,173.02；其中商誉减值1,546,544,866.49。利润表以负数列示损失。

影响：这是税前费用；确认减值不等于当期支付同额现金。

尚不能确定：税费、少数股东影响及各因素对归母利润下降的贡献未逐项核实，不能把税前减值等同于归母净利润下降额，也不能说它单独解释全部下降。
