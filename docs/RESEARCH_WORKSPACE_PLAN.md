2026-10-10 owner 要求按提案端到端交付，原 AC 不变。同日审阅本方案后明确批准通用导航框架演进，由独立QA复核后交付；六类注册点、安全与门禁不变。

- 沿用六类注册点。NavItem 增加可选 placement（primary/context/action/secondary）及页面 actions 声明；shell 只解释结构，不写公司业务路由。既有无 placement 插件仍按 group/children 渲染。修复 REQ-012 M4 分组先画标题再画全部链接的问题；URL 导航清除旧版本参数，异步响应按导航序号拒绝过时内容。
- 五个研究页使用共享上下文：概览、行情与估值、报告、数据和生成配置。全局入口为工作台、公司、任务；旧批次、迭代、命令均留可到达链接。浏览与导出离线，远程动作需计划与明确确认。
- 行情基于原始仓日 OHLC/daily_basic，日分位先按截至当日窗口计算，再抽取自然期间末点。复权必须有同日 factor；财务口径独立。图表数据契约与既有年末估算分离。
- agent/model 采用 `config/agent_models.json` 的本地目录。安装只验证可执行文件，登录与模型授权默认未验证；本地配置仅说明默认来源。具体模型以单次 `--model` 参数传递；无非法组合、全局配置写入、自动重试、自动降级。CLI 回报不足时实际模型为未知。产物按执行前后内容摘要核对，GUI 无本次声明报告时返回报告未产出。
- 报告正式版本只认发布指针/迭代台账。元信息未知时明确未知，PDF/JSON通过索引 id 与 jail读取；安全 Markdown 渲染、目录和只读比较不新增投资判断。
- 采集计划与确认绑定摘要，同一计划统计分母含未尝试。计划目标、已有记录、实际请求、缓存复用分别计数；批次结果只汇总该批目标。持久批次可恢复，图表范围需求由数据页显式确认。
