### Q4：为什么「在末尾补 7 行勾选」还不够

`acceptance_gate.py` 的 `checked()` 与 `unchecked()` 是**两个独立判定**，而 `evaluate()`
（第 311~315 行）**先看 `unchecked`**：

```python
if any(unchecked(text, ac) for text in scoped):
```

也就是说：只要报告里**任何一处**还留着未勾选行，补写 `- [x]` 也不会改变判定。我用门禁自己的函数
