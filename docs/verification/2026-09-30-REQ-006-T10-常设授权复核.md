方法：对**每个** tracked `.md`（138 个，基线 `origin/main` 下的全量）抽取
「`^## 验收标准` 到下一个 `^## `」的整段，以及所有 `^[-*] \*\*AC-[0-9]` 定义行，
在**基线 `origin/main` 与被复核提交 `e6aad7c` 之间**逐字比较：

```bash
BASE=origin/main; HEADREV=e6aad7c
git -c core.quotepath=false ls-tree -r --name-only "$BASE" | grep '\.md$' | while IFS= read -r f; do
  a=$(git show "$BASE:$f"   | awk '/^## 验收标准/{p=1} p&&/^## /&&!/^## 验收标准/{p=0} p')
  b=$(git show "$HEADREV:$f" | awk '/^## 验收标准/{p=1} p&&/^## /&&!/^## 验收标准/{p=0} p')
  [ "$a" != "$b" ] && echo "AC SECTION DIFFERS: $f"
  diff -q <(git show "$BASE:$f"   | grep -E '^[-*] \*\*AC-[0-9]' | sed 's/[[:space:]]*$//') \
          <(git show "$HEADREV:$f" | grep -E '^[-*] \*\*AC-[0-9]' | sed 's/[[:space:]]*$//') >/dev/null \
    || echo "AC BULLETS DIFFER: $f"
done
```

- 结果：**`checked 138 tracked .md at origin/main; differing AC sections: 0; differing bullet sets: 0`**。
