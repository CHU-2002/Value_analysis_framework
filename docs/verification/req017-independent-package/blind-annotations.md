### B1：新产品投产失利与技术转换引起库存及停产损失（高优先）

- 位置：PDF/印刷第2页“致股东的信”；第3页有关越南产能与美国政策的讨论。

- 事项：管理层自述2023年下半年产品研产销脱节，库存增加并形成巨额跌价；2024年下半年开始停产该产品、产线转为新一代BC技术，同时带来停产损失。另说明越南面向美国的产能受双反政策变化逐步停产，造成固定资产减值。

### B2：资产减值损失规模及口径（重大）

- 位置：PDF/印刷241–242页，财务报表附注“七、72 资产减值损失”；主要财务数据第11页。
- 原文短引：“存货跌价损失及合同履约成本减值损失”；“固定资产减值损失”。

- 限制：减值损失是利润表税前科目，不等于归母净利下降额；不能因为绝对规模接近就说其单独导致全部亏损。不得把本期损失与期末准备余额混用。资产减值并非当期同额现金流出。
